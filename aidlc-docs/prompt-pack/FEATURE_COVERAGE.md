# Roadmap coverage crosswalk

Every numbered section in the preceding feature blueprint is mapped below. Overlapping feature descriptions share task IDs rather than creating competing implementations. A mapped task is PLANNED, not built or accepted.

**Optional work remains explicitly gated, not omitted:** polygon annotation is W013–W014; standalone patch annotation is R015; printable PDF reports are A013; the animated HTML presentation is Z012; a prerecorded demo fallback is Z013; external notification delivery is E013; and UMAP/t-SNE is X010. These are later task prompts, not claims that the deliverables already exist. Real LIS/DICOM/clinical integrations, billing, arbitrary new pathology model families, and broad vendor-format support remain outside this approved educational demo roadmap.

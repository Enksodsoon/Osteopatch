# Preserved project evidence

This directory contains original AI-DLC decisions, source/provenance investigations, manifests, image QC, frozen model evaluations and workshop deployment records. It is a historical and scientific record, not a substitute for current operating instructions.

Start current work at [the documentation hub](../docs/README.md) and [AGENTS.md](../AGENTS.md). Inspect [AI-DLC state](aidlc-state.md) and the relevant evidence before changing a scientific contract. Preserve existing files, hashes and original wording. New experiments or verification results belong in new dated records; do not update old metrics in place.

The [G8 deployment summary](g8-deployment-summary.md) describes the workshop deployment at its recorded time. It is not proof of current credentials, service health or the latest deployed source revision.

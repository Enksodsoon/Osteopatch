Start with a
clean foundation.

The source checkout is enough to build this website, run the software tests and compile both user interfaces. Reviewing real patches requires a separate verified runtime bundle.

01 / Install the locked environment

Use Python 3.12, Node 24, Git and uv. Run commands from the repository root unless a directory change is shown. These commands do not provision AWS resources.

git clone https://github.com/Enksodsoon/Osteopatch.git
cd Osteopatch
uv sync --locked --extra dev
npm --prefix app/g6/frontend ci
npm --prefix app/g7-enterprise/frontend ci

02 / Verify the software

uv run --locked pytest app/g6/backend/tests app/g7-enterprise/backend/tests -q
python -m unittest discover -s tests/tooling -v
python scripts/check_repository.py
npm --prefix app/g6/frontend test
npm --prefix app/g6/frontend run build
npm --prefix app/g7-enterprise/frontend test
npm --prefix app/g7-enterprise/frontend run build

Tests requiring real model artifacts or optional image engines explicitly skip when those dependencies are absent. A skipped test is not a model-validation result.

03 / Prepare actual review data

The runtime is not bundled with Git.

Restore the approved runtime artifacts to runtime-artifacts/, or point OSTEOPATCH_RUNTIME_ARTIFACTS at an existing bundle. The preparation command verifies what is already present; it does not download a dataset or reconstruct a missing model.

uv run --locked python scripts/prepare_runtime.py

Expected artifact identities are recorded in the runtime contract. Keep a verified reference bundle and use a separate disposable review-database copy for tests. See the full setup guide for environment overrides and missing-artifact troubleshooting.

04 / Start the reviewer application

After the artifact checks succeed, use two terminals:

uv run --locked uvicorn osteopatch.app:app --app-dir app/g6/backend --host 127.0.0.1 --port 8137
npm --prefix app/g6/frontend run dev

Open 127.0.0.1:5173. The API health route is /v1/health on port 8137. Keep development services on loopback. The enterprise local identity issuer is not production authentication.

Build the documentation website

python scripts/build_site.py
python scripts/check_site.py
python -m http.server 8765 --bind 127.0.0.1 --directory _site

Open 127.0.0.1:8765. This path needs no model, dataset, npm package or cloud account. Stop the local server with Ctrl+C.

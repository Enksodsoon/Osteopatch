Local review path

React / Vite→FastAPI→SQLite + verified artifacts

The core application lives in app/g6. React uses /v1/* APIs. FastAPI reads source/QC metadata and immutable predictions while recording revision-aware review events. Ordinary review serving uses precomputed predictions; the optional attribution path has a separate model dependency.

Three records, not one mutable label

RecordResponsibilityBoundary
Source / QCOriginal labels, image identity, provenance and eligibility.Not overwritten by a reviewer.
PredictionThree scores, model identity and review-priority inputs.Immutable model output, not a diagnosis.
Review eventAccept, correct or defer, with revision and idempotency.Append-only; no silent retraining.

Enterprise extensions

app/g7-enterprise adds project tenancy, role-based capabilities, an audit chain, model-registry and governance surfaces. It imports the core review package rather than forking the clinical-domain contract. These are prototype features, not proof of production security or hospital readiness.

The historical folder names are retained because imports, tests and deployment contracts depend on them. New navigation and ownership make the structure clearer without a risky rename migration.

Historical workshop deployment

CloudFront→Private S3 / API Gateway→Lambda / DynamoDB

The AWS demo scopes image access to a deterministic 50-image subset. It is separate from the static GitHub Pages website and from the full local collection. Current source changes are not automatically assumed to exist in that deployment.

Not a production deployment guarantee.

The workshop stack needs an authentication, abuse-control, cost and backup review before any broader use. Infrastructure teardown can delete demo resources and must never be part of routine cleanup.

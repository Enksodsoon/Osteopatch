# Verification evidence

Each record describes a particular revision, environment and test scope. A point-in-time pass does not certify a later revision or a live deployment. Keep historical records; add a new dated result instead of rewriting old outputs.

Existing records include [baseline verification](step02-baseline.md), [static-analysis baseline](step04-static-baseline.md), [local smoke results](smoke-result.json) and [real-data browser results](e2e-ui-result.json). They do not imply that a clean clone includes the original runtime bundle.

Repository platform maintenance is documented in [repository-platform-2026-10-05.md](repository-platform-2026-10-05.md). Current GitHub Actions runs are the source for a specific commit's CI status. Scientific performance remains in the frozen G4/G5 evidence, separate from these software checks.

## Runtime capability records

- [runtime-capability.json](runtime-capability.json) — generated by `python scripts/runtime_capability.py`. Records which OPTIONAL runtimes a machine can actually use: torch / torchvision / grad-cam versions, the OpenSlide binding + native library version, the frozen encoder checkpoint's SHA-256 against its pin, the recovered head bundle's SHA-256 against its pin, and how many immutable predictions were readable. A torch-free machine is a valid configuration and is reported as such — capability is recorded, not gated. Regenerate with `--warm` to pre-fetch the encoder weights into `runtime-artifacts/`.
- [unified-surface.json](unified-surface.json) — generated by `python scripts/verify_unified_surface.py`. Drives the authenticated unified `/v1/*` surface over real HTTP, as each of the six demo personas, against a COPY of the read model. Records every route status, the capability gates that must reject, the tenancy 404s, and a before/after hash proving the canonical review store was never written.

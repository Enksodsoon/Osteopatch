# Decision and approval log — template

No entry in this template records an actual owner approval.

| Field | Value to record during execution |
|---|---|
| Decision ID / gate | Actual gate, such as G1 source or G6A deployment |
| Date/time and timezone | Actual decision time |
| Decision owner | Actual human decision maker |
| Artifact/version reviewed | Path and commit/hash |
| Question | Specific unresolved choice |
| Options and recommendation | Alternatives and trade-offs |
| Decision | Accepted, rejected or deferred |
| Authority boundary | Exact allowed action, spend/source/resource scope |
| What remains unapproved | Explicit exclusions |
| Evidence | Source, tool result, test or owner message |
| Next checkpoint | A single clear next action |

Keep rejected decisions and superseding decisions. Do not rewrite an old approval to cover a different model, dataset, deployment region or budget.

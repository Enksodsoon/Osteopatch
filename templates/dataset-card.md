# Dataset card — template

**Status:** not populated from an actual local dataset yet. See the approved source decision before filling this card.

## Identity and rights

Record source collection, DOI, release/version, actual retrieval URLs/object manifest, retrieval date, checksums, license and required attribution. Specify whether the exact IDC route was verified or TCIA direct was explicitly approved.

## Population and data unit

Record independently verified patients, slides and patches separately. Describe sampling, staining/magnification, dimensions, class definitions, annotation process and whether each image has a predominant label or a mask. Do not infer extra patients from the archival cohort description.

## Actual audit

Record downloaded/included/excluded counts, dimensions, corrupt files, unmatched labels, duplicate/near-duplicate groups, exact source aliases and resolved patient/slide mapping evidence. A published expected count is not a completed actual audit.

## Splits and permitted uses

Record grouping level, exact split hash, patient × class support, leakage tests, unresolved grouping limitations, development/validation/test roles and the locked test policy. State educational scope and no clinical/patient-level response claims.

## Changes

Record derivative image transformations, exclusions, revised source versions and expert-adjudicated amendments separately from the original labels.
